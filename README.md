
# 🌊 TravelMate — Travel Booking Website

TravelMate is a full-stack travel booking web application that allows users to explore destinations, book travel packages, and manage their bookings.

## ✨ Features

- Browse travel packages and destination details
- User registration and login
- Book travel packages with preferred dates and number of travelers
- View and cancel personal bookings
- Admin dashboard with booking statistics
- Admin booking confirmation and cancellation
- Booking status tracking (Pending, Confirmed, Cancelled)
- Responsive ocean-blue interface

## 🛠️ Technologies Used

**Frontend**
- React.js
- Vite
- HTML and CSS
- JavaScript

**Backend**
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- JWT Authentication

## 📁 Project Structure

TravelMate/
- frontend/ — React application
- backend/ — Express API and database models

## 🚀 Running Locally

### Backend

1. Open the `backend` folder.
2. Install dependencies with `npm install`.
3. Create a `.env` file with your own MongoDB connection string and JWT secret.
4. Start the backend with `node server.js`.

### Frontend

1. Open the `frontend` folder.
2. Install dependencies with `npm install`.
3. Start the development server with `npm run dev`.

## 🔐 Security

Environment variables, database credentials, and dependencies are excluded from Git using `.gitignore`.
